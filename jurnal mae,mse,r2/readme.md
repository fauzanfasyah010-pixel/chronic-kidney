## Penjelasan MAE, MSE, dan R²

### MAE (Mean Absolute Error)

Semakin mendekati 0, semakin baik karena rata-rata selisih absolut antara nilai aktual dan prediksi semakin kecil. Artikel menjelaskan bahwa MAE memiliki rentang nilai dari 0 hingga tak terhingga.




### MSE (Mean Squared Error)

Semakin mendekati 0, semakin baik karena rata-rata kuadrat kesalahan prediksi semakin kecil. Kesalahan besar mendapat penalti lebih tinggi karena dikuadratkan.


### R² (R-squared / Koefisien Determinasi)

Semakin mendekati 1, umumnya semakin baik karena model lebih mampu menjelaskan variasi data. Nilainya dapat negatif jika performa model lebih buruk daripada prediksi menggunakan rata-rata target.
